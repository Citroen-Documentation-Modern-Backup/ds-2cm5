D1CG0AP0Dépose - repose : Coffre de batterie supérieur
IMPERATIF : Seuls les personnels ayant reçu une formation spécifique aux véhicules électriques sont habilités à intervenir sur le véhicule (respecter la réglementation en vigueur dans le pays concerné).
1. Dépose
Lever et caler le véhicule.
IMPERATIF : Mettre le véhicule "hors tension partielle" (voir opération correspondante).
Déposer :
  • Le fusible du coffre batterie arrière
  • La barrette de sectionnement du coffre batterie avant supérieur
Figure : c5jp06uc
Désaccoupler la durit (1) Côté avant gauche.
ATTENTION : Prévoir l’écoulement du liquide.
Figure : d1cp023c
Accoupler la durit ( 1) Après évacuation complète du liquide de refroidissement.
Déposer :
  • Le bloc électronique (voir opération correspondante)
  • Les 2 écrous (2) Dégager le support-câbles
  • La batterie 12V
  • Les 2 écrous (3)
  • Les 2 écrous (4)
Écarter le réservoir de liquide de chauffage ( 5).
Déposer le pulseur de refroidissement (voir opération correspondante).
NOTA : Protéger le radiateur pour éviter d’abîmer les ailettes.
Figure : d1cp024d
Déconnecter le connecteur (6).
Désaccoupler les durits (7).
Desserrer les 2 vis (8).
ATTENTION : Protéger les porte-fusibles.
Déposer les câbles (9).
Déposer l’écrou (10).
Désaccoupler la durit (11) (repère violet).
Déposer les 3 vis (12).
Figure : d1cp025d
Déposer le support-tétines ( 13).
Élinguer le coffre batterie en " a".
Déposer le coffre à batterie À l’aide d’un moyen de levage.
ATTENTION : Prendre soin du câble d’ouverture de trappe de charge ( 14).
Déclipper les tétines de remplissage à l’arrière du coffre batterie supérieur.
2. Repose
Figure : d1cp026c
Reposer le coffre à batterie supérieur À l’aide d’un moyen de levage.
NOTA : Replacer le tuyau ( 15) Clipper les tétines de remplissage.
ATTENTION : Lors de cette opération, prendre garde de ne pas détériorer les câbles et les durits.
Figure : d1cp027d
Reposer :
  • Les 3 vis (12) Serrer à 12 m.daN
  • Le support-tétines (13)
  • Les 2 vis (3) Serrer
  • Les 2 câbles (9)
  • Les 2 vis (8) Serrer à 0,5 m.daN
Accoupler :
  • Les 2 durits (7)
  • La durit (11)
Reconnecter le connecteur (6).
Reposer :
  • L’écrou (10)
  • Le pulseur de refroidissement (voir opération correspondante)
Figure : d1cp028c
Reposer :
  • Le réservoir de liquide de chauffage ( 5)
  • Les 2 écrous (4)
  • Le support-câbles
  • Les 2 écrous (2)
  • La batterie 12V
  • Le bloc électronique (voir opération correspondante)
Remplir lentement le circuit avec du liquide de refroidissement (voir opération correspondante).
IMPERATIF : En cas d’échange du coffre de batterie : Effectuer une charge d’initialisation et une remise à niveau de l’électrolyte batterie (voir opération correspondante).
