B1GG01DGP0Dépose - repose : Motoventilateur (WMI 935, 936, 8BC, 8AD)
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie .
Déposer :
  • Les grilles de calandre
  • La protection sous moteur
  • Les pare-boue avant
  • Le pare-chocs avant
Figure : b1gg11qd
ATTENTION : Ne pas détériorer les ailettes du radiateur de refroidissement.
Déposer les 3 vis (1).
Écarter : Le motoventilateur (2) (Déconnecter le connecteur  (en "a")).
Déposer le motoventilateur (2) (par le bas).
2. Repose
Figure : b1gg11rd
ATTENTION : Nettoyer et lubrifier le connecteur  (en "c", "b") ; À l’aide d’un produit dégraissant homologué.
Reposer :
  • Le motoventilateur (2) (Faire coïncider le connecteur "a" (en "c", "b"))
  • Les 3 vis (1)
  • Le pare-chocs avant
  • Les pare-boue avant
  • La protection sous moteur
  • Les grilles de calandre
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
