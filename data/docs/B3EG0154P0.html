B3EG0154P0Dépose - Repose : Pompe d’assistance de direction
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Seuls les personnels ayant reçu une formation spécifique aux véhicules électriques sont habilités à intervenir sur le véhicule (respecter la réglementation en vigueur dans le pays concerné).
1. Outillage
Un outil de diagnostic.
2. Dépose
IMPERATIF : Effectuer la mise hors tension du véhicule .
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer :
  • La roue avant droite
  • La protection sous moteur
  • La transmission droite
Figure : b3eg0bhd
Désaccoupler le tuyau (Circuit basse pression)(en "a").
NOTA : Prévoir l’écoulement du liquide.
Manœuvrer la direction lentement de butée à butée dans les deux sens.
ATTENTION : Obturer les orifices des organes hydrauliques.
Figure : b3eg0bkd
Déconnecter le connecteur (En "b").
Dégrafer le faisceau électrique (En "c").
ATTENTION : Éviter l’écoulement du liquide de direction assistée sur les connecteurs du groupe électropompe .
Désaccoupler et écarter : Le tuyau haute pression (1).
Déposer :
  • Les vis (2)
  • Les brides (3)
  • Le groupe électropompe d’assistance de direction
3. Repose
ATTENTION : Respecter les couples de serrage.
ATTENTION : Préremplir le groupe neuf avant de le présenter sur véhicule.
Reposer :
  • Le groupe électropompe d’assistance de direction
  • Les brides (3)
  • Les vis (2)
Accoupler : Le tuyau haute pression (1).
Agrafer le faisceau électrique (En "c").
Connecter le connecteur (En "b").
Accoupler le tuyau (Circuit basse pression)(en "a").
Reposer :
  • La transmission droite
  • La protection sous moteur
  • La roue avant droite
  • Le véhicule sur ses roues
IMPERATIF : Effectuer la mise sous tension du véhicule .
Remplir et purger le circuit hydraulique d’assistance de direction.
4. Télécodage
Effectuer le télécodage du calculateur du groupe électropompe d’assistance de direction ; À l’aide d’un outil de diagnostic.
