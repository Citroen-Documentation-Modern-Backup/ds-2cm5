D6AN012DP0Identification : Boîtier de servitude intelligent
1. Introduction
Ce document permet l’identifier l’architecture électronique d’un véhicule à partir de l’identification d’un boîtier de servitude intelligent, ou de différencier deux boîtiers de servitude intelligents à partir de leurs caractéristiques physiques.
2. Guide de reconnaissance
Figure : d4ey00nd
"a" Type de véhicule sur lequel est monté ce boîtier de servitude intelligent.
"b" Niveau de finition du boîtier de servitude intelligent :
  • BG => Bas de gamme
  • MG => Moyenne gamme
  • HG => Haut de gamme
NOTA : En pièces de rechange, il sera fourni le boîtier de servitude intelligent haut de gamme.
