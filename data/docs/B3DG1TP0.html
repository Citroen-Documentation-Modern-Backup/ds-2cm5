B3DG1TP0Dépose - repose : Moyeu-roulement arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Outillage spécial
Figure : e5-p15pc
[ 1] manchon : 8401-T.M.
[ 2] bague d’appui : 8401-T.N.
Figure : e5-p15qc
[ 3] grain d’appui : 8401-T.P.
Figure : e5-p15rc
[ 4] tampon de montage : 8401-T.J.
2. Outillage préconisé
Figure : e5-p15sc
[ 5] Extracteur 3 branches : U20 FACOM.
Figure : e5-p15tc
[ 6] Extracteur 2 branches : U52 FACOM.
3. Dépose
Déposer le tambour de frein arrière.
NOTA : Avec antiblocage de roues : Déposer le capteur de roue .
Figure : b3dp03yc
Déposer le capuchon (1).
Figure : b3dp03zc
Déposer :
  • L’écrou
  • La rondelle
Figure : b3dp040c
Extraire le moyeu ( 4) à l’aide de l’outil [5] et du grain d’appui [3].
Figure : b3dp041c
Extraire la cage intérieure ( 5) du roulement à l’aide de l’extracteur [6] et du grain d’appui [3].
Déposer la coupelle ( 6) en utilisant deux tournevis.
4. Repose
Le moyeu-roulement est un ensemble indissociable, il faut donc le remplacer systématiquement après dépose.
Figure : b3dp042c
Nettoyer la fusée avant remontage.
Figure : b3dp043c
Mettre en place une coupelle d’appui de joint neuve à l’aide du tampon [ 4].
Figure : b3dp044c
Visser le manchon [ 1] sur la fusée.
Engager un moyeu-roulement (4) neuf sur le manchon guide [1].
Visser la bague [ 2] sur le manchon guide [1].
Serrer la bague [ 2] jusqu’à ce que le moyeu-roulement (4) soit en butée.
Déposer l’outillage.
Reposer :
  • La rondelle (3)
  • L’écrou (2) (graisser les filets et la face de l’écrou)
Serrer l’écrou (2) à 25 ± 2,5 m.daN.
Freiner l’écrou (2).
Reposer :
  • Un capuchon neuf (1)
  • Le tambour
NOTA : Avec antiblocage de roues : Reposer le capteur de roue .
