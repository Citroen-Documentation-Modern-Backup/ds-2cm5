2. Opérations préliminaires
Lever et caler l’avant droit du véhicule.
IMPERATIF : Mettre le véhicule "hors tension partielle" (voir opération correspondante).
Débrancher la batterie 12 volts.
3. Dépose
Figure : c5jp06jc
Déposer :
  • Les pions ( 1) À l’aide de l’outil [1]
  • Le pare-boue avant droit (2)
Figure : d1ap012c
ATTENTION : Les ergots " a" sont fragiles.
Déposer le volet de trappe de charge ( 3) : Faire coulisser le volet de trappe de charge (3) sur le porte-volet (4).
Figure : d1ap013c
Débloquer le volet de sécurité ( 7) en appuyant sur ses deux ergots (suivant flèches).
Maintenir le volet de sécurité ( 7) en position "basculé".
Déposer :
  • Les 4 vis (5)
  • Les 2 vis (6)
Figure : c4ap10yc
Ouvrir les colliers ( 8).
Figure : c4ap10zc
Déposer l’ensemble boîtier de charge ( 9) et entourage (10).
Déposer l’entourage ( 10) du boîtier de charge (9).
Figure : c4ap110c
Désaccoupler le verrouillage ( 11).
Déverrouiller le connecteur en " b".
Débrancher le connecteur (12) .
NOTA : Pour échanger le capteur de trappe de charge : Remplacer l’entourage (10) Le capteur de trappe de charge est inclus dans l’entourage (10).
4. Repose
Rebrancher le connecteur (12) .
Verrouiller le connecteur ( 12).
Accoupler le verrouillage ( 11).
Poser le boîtier de charge ( 9) dans l’entourage (10).
Reposer l’ensemble boîtier de charge ( 9) et entourage (10).
Agrafer le faisceau À l’aide des colliers (8).
Reposer :
  • Les 4 vis (5) (vis neuves)
  • Les 2 vis (6)
Serrer les 4 vis (5).
Serrer les vis (6) à 1,1 m.daN .
Libérer le volet de sécurité ( 7).
Reposer :
  • Le volet de la trappe de charge ( 3) (voir nota)
  • Le pare-boue avant droit (2)
  • Les pions (1)
NOTA : Faire coulisser le volet de trappe de charge ( 3) sur le porte-volet (4). Contrôler le verrouillage des ergots "a".
5. Opérations complémentaires
Replacer le véhicule sur le sol.
