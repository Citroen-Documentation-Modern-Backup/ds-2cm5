D4EB3LP0Présentation : Éclairage extérieur / signalisation
DEPUIS OPR 9457
1. Préambule
Le véhicule est équipé des nouvelles fonctions suivantes :
  • Module de commutation sous volant de direction
  • Allumage automatique des feux de détresse
  • Commande impulsionnelle des feux de brouillard
  • Boîtier de servitude moteur (BSM), qui gère le fonctionnement des feux situés à l’avant du véhicule, ainsi que l’avertisseur sonore
1.1. Gestion de l’éclairage
Les fonctions éclairage extérieur et signalisation assurent la gestion du fonctionnement de différents organes

NOTA : Les feux de recul et les feux de stop sont actionnés directement par leurs contacteurs respectifs. L’information sur l’état des contacteurs est acquise par le BSI.
1.2. Allumage des feux de croisement et des feux de détresse
L’allumage ou l’extinction des feux de croisement s’effectue manuellement. L’utilisateur actionne une commande depuis le module de commutation sous volant de direction ou depuis un contacteur.
L’allumage automatique des feux de détresse en cas de forte décélération est uniquement sur les véhicules équipés du contrôle dynamique de stabilité (ESP).
2. Description du boîtier de servitude moteur
Le boîtier de servitude moteur commande les relais de puissance du véhicule sur ordre du boîtier de servitude intelligent via le réseau VAN CAR 1. Le BSM est situé sous le capot moteur.
Le boîtier de servitude moteur est constitué de deux modules associés :
  • Module 1 : Module intégrant les maxi fusibles  (b)
  • Module 2 : Module intégrant une carte électronique, les fusibles et les relais  (a)
Figure : d4ep02yd
Légende :
  • "a" : Module intégrant une carte électronique, les fusibles et les relais
  • "b" : Module intégrant les maxi fusibles
  • "c" : Étiquette d’identification produit
