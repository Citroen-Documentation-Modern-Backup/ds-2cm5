B1HG025SP0Dépose - repose : Réservoir de carburant additionnel (Flex Fuel)
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie.
1.1. Réservoir de carburant additionnel
Figure : b1hg3ofd
Désaccoupler le raccord  (en "a").
Déconnecter le connecteur (en "b").
Figure : b1hg3ogd
Déposer les vis (1).
Figure : b1hg3ohd
Ouvrir le collier (2).
Désaccoupler le tube  (en "c").
Déposer le réservoir additionnel (3).
1.2. Pompe électrique du réservoir additionnel
Figure : b1hg3oid
Déposer la pompe électrique (4) ((suivant flèche "d")).
Figure : b1hg3ojd
Déposer le joint d’étanchéité (5).
2. Repose
2.1. Pompe électrique du réservoir additionnel
ATTENTION : Remplacer systématiquement le joint d’étanchéité (5).
Reposer :
  • Le joint d’étanchéité (5) (neuf)
  • La pompe électrique (4)
2.2. Réservoir de carburant additionnel
Reposer le réservoir additionnel (3).
Accoupler le tube  (en "c").
Refermer le collier (2).
Reposer les vis (1).
Connecter le connecteur  (en "b").
Accoupler le raccord  (en "a").
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
