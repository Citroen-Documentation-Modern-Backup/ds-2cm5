2. Démontage bielles/pistons
Figure : b1dp1t8d
Déposer les axes de pistons à la presse ; À l’aide des outils [2], [3] et [4].
IMPERATIF : Cette opération implique l’échange des pistons (inutilisables après démontage).
3. Remontage Bielles/pistons (Outillage PEUGEOT)
Figure : b1dp1t9d
Monter l’axe ( 1) du premier piston sur le guide axe de piston [3].
Visser à la main la poignée [ 4] sans forcer (jusqu’en butée).
Placer sur le socle [1] l’appui [2].
Ouvrir la pince (en "a").
Dévisser au maximum les poussoirs (en "b").
Figure : b1dp1tad
Positionner le piston sur l’outil [1], la flèche et le marquage orienté vers le haut.
Placer la bielle dans le piston, les arrêts de coussinets " c" orientés suivant dessin.
NOTA : Bielles montées dans le carter cylindres, les arrêts de coussinets " c" sont situés côté admission.
Figure : b1dp1tbd
Bielles munies d’un orifice de lubrification :
  • Bielles montées dans le carter cylindres, l’orifice de lubrification " d" est situé côté admission
  • L’orifice de lubrification "d" est situé du même côté que les arrêts de coussinets "c"
Positionner le piston sur l’appui [ 2] et le guider avec l’ensemble poignée/axe/embout de guidage.
Introduire la broche (en "e").
Visser les poussoirs (/) jusqu’au contact du piston (en "b").
Serrer les écrous (en "f").
Figure : b1dp1tcd
Retirer la broche (en "e").
Verrouiller le piston.
Placer la bielle avec son chapeau (sans coussinet) dans le piston et la centrer avec l’ensemble poignée/axe/embout de guidage.
Régler la position et la hauteur de l’appui de bielle en " g" pour obtenir :
  • Le contact de l’appui en "g" sous la bielle
  • Jeu (A) : 0,1 mm
Serrer le contre-écrou (en "h").
Figure : b1dp1tdd
Disposer le pied des bielles sur un réchaud électrique.
Placer sur chaque pied de bielle un morceau de soudure à l’étain (en "j").
Chauffer jusqu’à la fusion du morceau d’étain (température de 250°C environ).
IMPERATIF : Huiler les axes de piston.
Essuyer la goutte d’étain.
ATTENTION : La réussite des opérations est conditionnée par la rapidité d’exécution : L’axe doit être emmanché d’un seul mouvement.
Reposer l’axe de piston pour l’assemblage bielle-piston.
Procéder de la même manière pour les trois autres ensembles.
4. Remontage Bielles/pistons (Outillage CITROËN)
Figure : b1dp1ted
Placer l’axe du piston ( 1) sur le guide axe de piston [3].
Visser la poignée [ 4] sur le guide axe de piston sans serrer.
NOTA : L’axe ( 1) doit être libre en rotation.
Figure : b1dp1tfd
Placer l’outil [ 2] sur l’outil [6].
Positionner le piston ( 2) sur l’outil [2], la flèche et le marquage orienté vers le haut.
Centrer l’ensemble avec le guide axe de piston [ 3] et l’axe de piston.
Maintenir le piston avec la bride [/] du socle de positionnement [6].
Figure : b1cp05nc
Placer le pied de bielle sur une plaque chauffante électrique.
Figure : b1dp1tgd
Placer un morceau de soudure à l’étain sur le pied de bielle "" (en "k").
Chauffer jusqu’à la fusion du morceau d’étain (température de 250°C environ).
Figure : b1dp1thd
IMPERATIF : Avant montage, huiler l’axe de piston ( 1).
Placer la bielle dans le piston, en orientant le trou de graissage " l" (voir figure).
Engager rapidement l’axe ( 1) jusqu’en butée.
Attendre quelques secondes pour déposer l’ensemble bielle-piston.
Essuyer la goutte d’étain.
Procéder de la même manière pour les trois autres ensembles.
