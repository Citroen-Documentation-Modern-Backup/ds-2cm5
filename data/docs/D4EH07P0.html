D4EH07P0Procédures d’apprentissage et de programmation : Boîtier de servitude intelligent (BSI) - Électronique de contrôle moteur (ECM)
1. Outillage de diagnostic
Station "LEXIA" : 4171-T.
Station "PROXIA" : 4165-T.
ATTENTION : Les BSI, les ECM et les clés sont affectés à un véhicule et ne peuvent donc pas être échangés entre deux véhicules.
IMPERATIF : Le code confidentiel véhicule est nécessaire pour toutes ces opérations.
2. Apprentissage d’un BSI
NOTA : Cette procédure d’apprentissage intègre de façon automatique l’apprentissage des clés du véhicule.
2.1. Procédure d’apprentissage avec l’outil de diagnostic " LEXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "apprentissage"
  • "APPRENTISSAGE BSI"
Suivre les instructions données par l’outil de diagnostic.
La procédure d’apprentissage terminée, effectuer les opérations suivantes :
  • Synchronisation des télécommandes PLIPS HF (voir opération correspondante)
  • Vérifier le télécodage du BSI
  • Réinstaller, si nécessaire, les accessoires ajoutés au véhicule
  • Effectuer l’appairage avec le BSI (voir opération correspondante)
2.2. Procédure d’apprentissage avec l’outil de diagnostic "PROXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "TÉLÉCHARGEMENT/TÉLÉCODAGE"
  • "TÉLÉCODAGE"
  • Sélectionner le véhicule
  • "APPRENTISSAGE DU BSI"
Suivre les instructions données par l’outil de diagnostic.
La procédure d’apprentissage terminée, effectuer les opérations suivantes :
  • Synchronisation des télécommandes PLIPS HF (voir opération correspondante)
  • Vérifier le télécodage du BSI
  • Réinstaller, si nécessaire, les accessoires ajoutés au véhicule (voir opérations correspondantes)
  • Effectuer l’appairage avec le BSI (voir opération correspondante)
3. Programmation d’une ECM
NOTA : Cette procédure d’apprentissage est valable pour les outils de diagnostic LEXIA et PROXIA.
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR ECM"
  • "PROGRAMMATION/APPAIRAGE"
Suivre les instructions données par l’outil de diagnostic.
Effectuer l’appairage avec le BSI (voir opération correspondante).
4. Appairage
NOTA : Cette procédure d’appairage est valable pour les outils de diagnostic LEXIA et PROXIA.
Pour le menu "appairage", suivre la procédure de programmation ECM.
Répondre :
  • "NON", pour entrer un nouveau code confidentiel
  • "OUI", pour effectuer un appairage avec le BSI
Suivre les instructions données par l’outil de diagnostic.
