B1HG1GP0Dépose - repose : Réservoir carburant
1. Dépose
Vidanger le réservoir à l’aide d’une station de vidange.
Figure : b1hp0hzc
NOTA : La dépose du réservoir à carburant ne nécessite pas la dépose de la ligne d’échappement ( 1).
Déposer l’écran thermique (2).
Figure : b1hp0j0c
Débrancher :
  • La connexion électrique (3)
  • Le tuyau de sortie de filtre (4)
  • Le tuyau de retour carburant (5)
Figure : b1hp0j1c
Débrancher la tubulure de remplissage ( 6).
Débrider les tuyaux ( 7) - (8).
Figure : b1hp0j2c
Déclipper les câbles de frein de stationnement ( 9) du réservoir.
Déposer :
  • Le demi-berceau ( 10)
  • Les vis (11)
Figure : b1hp0j3c
Débrancher et débrider les tuyaux de mise à l’air libre ( 12).
Figure : b1hp0j4c
Débrancher le tuyau de dégazage ( 7).
Passer le câble de frein de stationnement droit au-dessus du réservoir ( 9).
Figure : b1hp0j5c
Sortir le réservoir par le côté droit du véhicule.
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
