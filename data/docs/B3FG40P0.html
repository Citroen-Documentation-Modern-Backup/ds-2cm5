2. Repose
Reposer :
  • L’amplificateur de freinage
  • Les écrous (14)
  • L’axe (15) et son agrafe élastique
Serrer les écrous (14) à 2,2 ± 0,1 m.daN.
Reposer la garniture intérieure .
Reposer :
  • Le support bloc hydraulique ( 12)
  • Les écrous (13)
Serrer les écrous (13) à 1,5 ± 0,3 m.daN.
Reposer :
  • Le bloc hydraulique (11)
  • Les écrous (10)
Serrer les écrous (10) à 1,5 ± 0,3 m.daN.
Reconnecter le connecteur en "b".
Accoupler les canalisations ( 9) Serrer à 1,5 ± 0,3 m.daN.
Reposer :
  • Le maître-cylindre (5)
  • Les écrous (7)
Serrer les écrous (7) à 2 ± 0,2 m.daN.
Accoupler les canalisations ( 6) Serrer à 1,5 ± 0,3 m.daN.
Accoupler le tube de dépression ( 8) de l’amplificateur de freinage.
Connecter le connecteur en "a".
Reposer :
  • Le support de batterie (3)
  • Les écrous (1)
  • Les vis (2)
  • La batterie
