C4BS07P0Déshabillage - Habillage : Porte arrière battante
2 PORTES AR BATTANTES VITREES DEPUIS OPR 7085
NOTA : Cette opération est effectuée sur la porte la plus équipée.
1. Opérations complémentaires
Dépose-pose :
  • Porte arrière
  • Troisième feu stop
2. Déshabillage
Figure : c4bp096d
Soulever le cache ( 1) du porte-balai.
Débrancher le tuyau de lave-vitre (2).
Déposer :
  • L’écrou (3)
  • L’ensemble porte-balai (4)
  • Le caoutchouc (5)
Figure : c4bp097d
Décrocher l’arrêt de porte ( 6) de la caisse.
Dégrafer :
  • Le câble (7) (avec un tournevis)
  • Le câble (8) (avec un tournevis)
Déposer :
  • Les vis (9)
  • L’arrêt de porte (10)
  • Le cache (11)
  • Les vis (12)
  • La serrure supérieure (13)
  • Les écrous (14)
  • L’écrou , La rondelle (15)
  • Le mécanisme d’essuie-glace (16) en faisant pivoter la tringle de liaison suivant la flèche
  • Les vis (17)
  • La serrure inférieure (18)
Figure : c4bp098c
Déposer le cache (19).
Chasser les clous de rivets avant le perçage.
Percer les rivets ( 20) avec un foret Ø 6 mm.
Dégager la liaison (21) poignée extérieure serrure.
Déposer :
  • La poignée (22)
  • Les vis (23)
Figure : c4bp099d
Dégager :
  • L’agrafe (24) (par rotation)
  • La tige de liaison (25)
Déposer :
  • La fourchette (26)
  • Le barillet (27) (par rotation)
  • La poignée (28)
  • Le joint d’étanchéité (29)
  • Chasser les clous de rivets avant le perçage
  • Percer les rivets (30) avec un foret Ø 4,2 mm
  • Déposer le joint (31)
Figure : c4bp09ac
Dégrafer la baguette de protection ( 32).
3. Habillage
Procéder dans l’ordre inverse des opérations de dépose.
