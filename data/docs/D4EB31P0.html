D4EB31P0Présentation : Système audio
DEPUIS OPR 9457
1. Préambule
Le véhicule peut être équipé des éléments suivants :
  • Autoradio  (avec lecteur cassette, avec lecteur de disques compacts ou avec radiotéléphone)
  • Changeur de disques compacts
  • Commande de système audio intégrée au module de commutation sous volant de direction
On distingue les 2 types d’autoradio suivants
Appellation Description
RB3 Récepteur radio équipé d’un lecteur de cassette mécanique
RD3 Récepteur radio équipé d’un lecteur de disques compacts
Ces 2 types d’autoradio sont liés à l’écran multifonction et peuvent être associés à une commande sous volant de direction (voir chapitre 3, commande sous volant de direction).
Ces 2 types d’autoradio possèdent également une entrée audio changeur de disques compacts.

3.3. Commande audio sous volant de direction
Figure : d4ap02sd
Position Fonctionnalité
a Bouton de réglage du volume "+"
b Molette de changement des présélections radio
c Bouton d’avance rapide/bouton de recherche montante (selon la source audio sélectionnée : tuner, changeur de disque compact, piste de disque compact, cassette, téléphone)
d Bouton de retour rapide/bouton de recherche descendante (selon la source audio sélectionnée : tuner, changeur de disque compact, piste de disque compact, cassette, téléphone)
e Bouton de réglage du volume "-"
f Bouton de changement de mode (changeur de disque compact, téléphone, cassette, tuner)
NOTA : L’appui simultané sur les touches "a" et "e" permet de commander la fonction "mute".
