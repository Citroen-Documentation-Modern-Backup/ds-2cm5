D5BM09P0Installation - Désinstallation : Accessoires
1. Outillage de diagnostic
Station "LEXIA" : 4171-T.
Station "PROXIA" : 4165-T.
2. Autoradio : Installation
2.1. Procédure à suivre avec l’outil de diagnostic "LEXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "ÉQUIPEMENT"
  • "AUTORADIO"
  • "INSTALLATION"
Suivre les instructions données par l’outil de diagnostic.
2.2. Procédure à suivre avec l’outil de diagnostic " PROXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "TÉLÉCHARGEMENT/TÉLÉCODAGE"
  • "INSTALLATION/DÉSINSTALLATION"
  • Sélectionner le véhicule
  • "AUTORADIO"
  • "INSTALLATION D’UN ÉQUIPEMENT"
Suivre les instructions données par l’outil de diagnostic.
