D4EM2QP0Opérations après-vente : Système audio
DEPUIS OPR 9457
1. Autoradio
1.1. Lecture des défauts
Il est possible de lire les défauts suivants à l’aide de l’outil de diagnostic :
  • Absence de communication avec l’écran multifonction
  • Dysfonctionnement de l’autoradio
1.2. Lecture des paramètres
Il est possible de lire les paramètres suivants à l’aide de l’outil de diagnostic
Paramètre État du paramètre Définition du paramètre
Numéro de série du véhicule Code VIN Permet de lire le code VIN du véhicule
Identification de l’autoradio par code VIN Non mémorisé. Mémorisé Permet de vérifier si le code VIN est mémorisé dans l’autoradio
Zone géographique d’utilisation Europe Occidentale. JAPON. Amérique Latine. Asie. Inde. Europe de l’Est. Arabie. Autres pays Permet de vérifier si l’autoradio est configuré pour la bonne zone géographique
Fader et haut-parleurs arrière Inactif/actif Permet de vérifier si l’autoradio est configuré pour 2 ou 4 sorties audio
Bande AM Inactif/actif Permet de vérifier si l’autoradio est configuré pour un véhicule électrique(inactif pour l’électrique)
Asservissement du niveau sonore en fonction de la vitesse véhicule Inactif/actif Permet de vérifier si le volume de l’autoradio est asservi à la vitesse du véhicule
Configuration des sorties audio Sortie haut-parleurs . Sorties ampli Permet de vérifier le format du signal de sortie de l’autoradio(avec ou sans amplificateur)
Loi de correction du niveau de volume Loi N° 0 à loi N° 15 Permet de vérifier la table d’asservissement sonore utilisée
1.3. TESTS ACTIONNEURS
Il est possible d’effectuer les tests suivants à l’aide de l’outil de diagnostic :
  • Recherche montante des fréquences
  • Émission d’un signal sonore répétitif sur la sortie audio avant gauche
  • Émission d’un signal sonore répétitif sur la sortie audio avant droite
  • Émission d’un signal sonore répétitif sur la sortie audio arrière gauche
  • Émission d’un signal sonore répétitif sur la sortie audio arrière droite
  • Éclairage de la façade de l’autoradio
1.4. Télécodage
Il est possible de télécoder les paramètres suivants à l’aide de l’outil de diagnostic :
  • Configuration du code VIN
  • Configuration de la zone géographique du tuner
  • Activation de l’asservissement du volume à la vitesse du véhicule
  • Configuration du format des sorties audio
  • Configuration du nombre de sorties actives
  • Activation/neutralisation de la bande AM
  • Loi de correction du niveau de volume
2. Changeur CD
2.1. Lecture des défauts
Il est possible de lire les défauts suivants à l’aide de l’outil de diagnostic :
  • Défaut absence de communication avec l’écran multifonction
  • Défaut de fonctionnement du mécanisme
  • Défaut de la sortie audio
2.2. Lecture des paramètres
Il est possible de lire les paramètres suivants à l’aide de l’outil de diagnostic
Paramètre État du paramètre Définition du paramètre
Nombre de disques présents De 0 à 6 Permet de connaître le nombre de disques compacts présents dans le changeur CD
2.3. TESTS ACTIONNEURS
Il est possible d’effectuer les tests suivants à l’aide de l’outil de diagnostic
arrêt Permet de vérifier si le changeur CD s’arrête correctement
PAUSE Permet de vérifier si le changeur CD effectue une pause en lecture
Lecture Permet de vérifier si le changeur CD effectue correctement la lecture
Changement de disque Permet de vérifier si le changeur CD effectue correctement le changement de disque
Intro scan Permet de vérifier si le changeur CD passe bien d’une plage à une autre au bout de quelques secondes de lecture
2.4. Télécodage
Il n’existe aucun télécodage pour cette fonction à l’aide de l’outil de diagnostic.
