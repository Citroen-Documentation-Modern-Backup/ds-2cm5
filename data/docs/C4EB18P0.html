2.3. Inserts gonflants
Les caisses sont livrées avec des inserts gonflants.
Lors de l’échange sur le véhicule d’un élément comprenant un insert gonflant, le réparateur doit effectuer les opérations suivantes :
  • Positionner l’insert gonflant dans l’élément
  • Faire une injection de mousse polyuréthane "C6"
NOTA : La mousse polyuréthane d’origine ne se développe qu’à une température de 165°C.
