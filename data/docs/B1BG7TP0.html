2. Opérations préliminaires
Lever et caler le véhicule, roues avant pendantes.
Débrancher la batterie .
Déposer :
  • Les roues avant
  • Les pare-boue avant
  • La courroie d’accessoires (voir opération correspondante)
  • Les écrous de transmissions À l’aide de l’outil [5]
  • Les écrous de fixation des rotules inférieures
  • Les transmissions (voir opération correspondante)
Vidanger :
  • La boîte de vitesses
  • Le circuit de refroidissement (voir opération correspondante)
ATTENTION : Lors de l’accouplement de l’outil [ 4], se protéger à l’aide d’un chiffon afin d’éviter toutes projections de carburant.
Raccorder l’outil [ 4] sur la valve de purge du circuit d’alimentation carburant et recueillir le carburant dans un récipient.

4. Repose
ATTENTION : (*) Voir gamme : Couples de serrage.
Lever le véhicule.
Présenter l’ensemble moteur-boîte de vitesses À l’aide des outils [1] et [2].
Reposer :
  • L’ensemble moteur-boîte de vitesses
  • Les vis de fixation des supports moteur
Dégager les outils [ 1] et [2].
Effectuer le serrage des supports moteur (*).
Reposer :
  • La biellette anticouple (*)
  • Le catalyseur (joint neuf) (*)
  • Le compresseur de réfrigération (*)
  • La courroie d’entraînement des accessoires (voir opération correspondante)
  • Le radiateur de refroidissement
Accoupler :
  • L’ensemble durits du boîtier de chauffage
  • Le tube d’assistance de freinage
  • Le câble d’embrayage
  • Le câble de masse
Connecter les connecteurs et les faisceaux électriques attenants au moteur.
Clipper les rotules de commande de vitesses sur la boîte de vitesses.
Reposer :
  • Les transmissions (voir opération correspondante)
  • Les pare-boue avant
  • Les roues avant
Effectuer le remplissage d’huile de la boîte de vitesses (voir opération correspondante).
Remplir et purger le circuit de refroidissement moteur (voir opération correspondante).
Remplir et purger le circuit d’assistance de direction (si nécessaire) (voir opération correspondante).
