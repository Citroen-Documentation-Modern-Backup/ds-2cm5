C5HG1VP0Dépose - repose : Réservoir à carburant
IMPERATIF : Seuls les personnels ayant reçu une formation spécifique aux véhicules électriques sont habilités à intervenir sur le véhicule (respecter la réglementation en vigueur dans le pays concerné).
1. Outillage préconisé
Figure : e5-p088c
Repère Désignation Référence Référence
[1] pince pour dépose et repose des colliers élastiques CLIC 4145-T (-).0172
2. Dépose
IMPERATIF : Mettre le véhicule "hors tension" (voir opération correspondante).
Vidanger le réservoir de carburant.
Figure : c5hp08uc
Déposer le collier (2).
Désaccoupler la goulotte ( 3).
Déposer l’écrou (1).
Basculer le support de réservoir ( 4).
Désaccoupler le tuyau (5) À l’aide de l’outil [1].
Figure : c5hp08vc
Désaccoupler :
  • Le tuyau (6)
  • Le tuyau d’alimentation carburant (7) À l’aide de l’outil [1]
Déconnecter le connecteur (8).
Déposer les sangles ( 9).
Déposer le réservoir de carburant.
3. Repose
Reposer le réservoir de carburant.
Reposer les sangles ( 9).
Reconnecter le connecteur (8).
Accoupler :
  • Le tuyau d’alimentation carburant (7) À l’aide de l’outil [1]
  • Le tuyau (5) À l’aide de l’outil [1]
  • Le tuyau (6)
Mettre en place le support de réservoir ( 4).
Reposer l’écrou ( 1).
Accoupler la goulotte ( 3).
Reposer un collier ( 2).
Serrer l’écrou (1) à 2 m.daN.
