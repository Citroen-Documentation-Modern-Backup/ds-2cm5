B2CT10P0Évolution : Boîte de vitesses type MA5
BVM MA DEPUIS OPR 9786 OU BVM MA PILOTEE DEPUIS OPR 9786
1. Application
Véhicules concernés :
  • Véhicules équipés d’une boîte de vitesses mécanique type MA5
  • Véhicules équipés d’une boîte de vitesses manuelle pilotée type MA5
Application : À partir du N° OPR 9786.
2. Description
Éléments modifiés :
  • carter de boîte de vitesses
  • carter d’embrayage
3. Identification
Suite à ces évolutions, toutes les boîtes de vitesses type MA5 comportent un nouveau numéro de séquence.
Anciennes séquences de boîtes de vitesses Nouvelles séquences de boîtes de vitesses
20 CN ... 20 CP ...
20 CF ...
4. Boîte de vitesses manuelle - Boîte de vitesses manuelle pilotée
Ajout d’une vis de fixation entre le carter d’embrayage et le carter de boîte de vitesses.
5. Boîte de vitesses manuelle pilotée
Modification sur carter de boîte de vitesses :
  • Nouvelle implantation du bouchon de vidange
  • Suppression du bouchon de niveau d’huile
  • Implantation d’un logement pour le capteur de position boîte de vitesses au point mort
6. Ancien montage
Figure : b2cp3w0c
(1) Bouchon de niveau d’huile.
(2) bouchon de vidange.
7. Nouveau montage
Figure : b2cp3w1c
" a" Logement du capteur de position boîte de vitesses au point mort.
" b" Nouvelle implantation du bouchon de vidange.
(3) Nouvelle vis de fixation.
8. Pièces de rechange
Le service "Pièces de Rechange" commercialise les anciennes et les nouvelles pièces.
À épuisement du stock, seules les nouvelles pièces seront disponibles au Service des Pièces de Rechange.
9. Réparation
Le panachage ou l’échange entre anciennes et nouvelles pièces est prohibé.
